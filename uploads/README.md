# uploads/

Put your own media here and reference it from `data/*.json`:

- `team/`     — member portraits, e.g. `uploads/team/firstname-lastname.jpg` (use the `img` key in `data/committees.json`)
- `gallery/`  — festival photos for `data/gallery.json`
- `sponsors/` — sponsor logos (transparent PNG or SVG) for `data/sponsors.json`

Keep file names lowercase with hyphens; JPG/WebP for photos, PNG/SVG for logos.
